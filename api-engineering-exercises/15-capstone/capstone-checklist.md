# Capstone Checklist

## Contract

- [ ] OpenAPI examples validate
- [ ] Every status/error documented
- [ ] Compatibility tests exist

## Data

- [ ] Constraints protect invariants
- [ ] Transactions protect multi-step writes
- [ ] Pagination ordering is stable

## Security

- [ ] Authentication verified
- [ ] Resource authorization tested
- [ ] Inputs and rates bounded
- [ ] Secrets excluded from logs

## Reliability

- [ ] External deadlines
- [ ] Idempotent retries
- [ ] Graceful shutdown
- [ ] Restore tested

## Operations

- [ ] Request IDs
- [ ] Structured logs
- [ ] Golden-signal metrics
- [ ] Actionable alerts/runbook
