# Engineering Capstones

Large projects that force integration across CS, systems, networking, databases, distributed systems, and production engineering.

## How to work

Work through the lessons in numerical order. Each lesson should contain a clear objective, a small amount of theory, one worked example or reference, a hands-on task, verification, and a transfer challenge.

Do not treat the reference implementation as the exercise. Read it after attempting the task, then reproduce the idea in a different problem.
