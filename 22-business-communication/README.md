# 22 — Business Communication

Four lessons on written and spoken professional communication: structuring messages, professional email conventions, oral presentation, and meetings/collaboration.

This track exists because it's the one genuine gap between the DART curriculum's existing scope and a full LIG S1 course list — everything else (algorithms, C, OS, computer architecture, math, databases) already has a full, deep track elsewhere in this repository. See `LIG-S1-MAP.md` at the repo root for the complete mapping.
