# Lesson 2: Proof, Tests, and Evidence

Every important claim needs evidence: a test, trace, benchmark, diagram, experiment, or documented invariant.

## Tasks

1. Read the lesson notes.
2. Perform the experiment or exercise.
3. Record what you observed.
4. Explain why it happened without hand-waving.

## Done when

You can explain the result from first principles and reproduce it from a clean checkout.
