# External Reference Repositories

These are deliberate dependencies of the curriculum. They are not duplicated into this repository. The point is to learn from authoritative material and keep this repository focused on your work.

| Area | Resource | Use it for |
|---|---|---|
| CS foundation | https://github.com/ossu/computer-science | Broad CS map and course sequencing |
| Tools | https://missing.csail.mit.edu/ | Shell, Git, debugging, profiling, tooling |
| Computer architecture | https://www.nand2tetris.org/ | Digital logic through computer construction |
| Go/TDD | https://github.com/quii/learn-go-with-tests | Go fundamentals through testing |
| Go projects | https://github.com/gophercises | Additional practical Go exercises |
| Build from scratch | https://github.com/codecrafters-io/build-your-own-x | Project ideas across systems and programming |
| OS | https://github.com/mit-pdos/xv6-riscv | Kernel and OS implementation labs |
| Networking | https://cs144.github.io/ | TCP/network-stack labs |
| Database internals | https://github.com/cmu-db/bustub | Storage engine and DBMS implementation |
| Distributed systems | https://pdos.csail.mit.edu/6.5840/ | Raft, replication, fault tolerance, distributed algorithms |
| Engineering practice | https://google.github.io/eng-practices/ | Code review and engineering discipline |
| Calculus | https://ocw.mit.edu/courses/18-01sc-single-variable-calculus-fall-2010/ | University single-variable calculus with independent-study materials |
| Linear algebra | https://ocw.mit.edu/courses/18-06-linear-algebra-spring-2010/ | University linear algebra |

| Discrete mathematics | https://ocw.mit.edu/courses/6-042j-mathematics-for-computer-science-spring-2015/ | Proofs, discrete structures, counting, graph theory, probability |

## Rule for using external material

The external repository is the source of theory or the lab. Your work here should record what you learned, experiments you ran, bugs you found, and the final implementation or notes you produced. Do not copy an entire external course into this repository.
